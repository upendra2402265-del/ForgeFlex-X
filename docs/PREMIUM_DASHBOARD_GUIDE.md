## Main demonstration order
1. COMMAND CENTER — 24-hour dispatch and baseline-vs-ForgeFlex comparison.
2. FLEXDNA — process-level flexibility and schedule timing.

4. FORECAST — actual vs forecast evidence.

## Design principles
- Use the main dispatch plot as the primary jury visual.
- Use the validation tab to prove the decision is feasible.
- Use the FlexDNA tab to explain the project novelty.
- Use scenario changes to demonstrate that the output is recomputed under different conditions.
- Keep impact claims clearly labeled as model outputs because the current dataset is synthetic.
